# FaceSwapEasy — phone-only APK build

1. Create a GitHub repository named FaceSwapEasy.
2. Upload the project files, including `.github/workflows/build-apk.yml`.
3. Open **Actions** → **Build Face Swap APK**.
4. Wait for the workflow to finish.
5. Open the completed run and download **FaceSwapEasy-debug**.
6. Extract it and install `app-debug.apk` on Android.

This is a starter build. It currently detects faces and creates a preview; true pixel-level face replacement and video face swapping still need to be implemented.
